# 회의록 보고서

**회의내용을 간결하고 핵심정리를 하는 앱**

음성·녹화 파일이나 회의 링크, 메모, 참석자, 일시를 넣으면 회의 내용을 받아 적고
«핵심 요약 · 결정사항 · 할 일»로 정리해 회의록을 만들어 주는 웹앱입니다.
정리는 자동이지만 **확정은 사람이 버튼으로** 결정하고, 확정하면 WORD · PDF · HTML로
내려받을 수 있습니다.

- 사용 규모: 팀·모임 10명 이내 (아는 사람만 접속)
- 받는 정보: 녹음·녹화 파일, 링크, 메모, 참석자, 일시 — **이름·연락처 등 개인정보는 받지 않습니다**
- 화면: 검정·회색 계열, 컴퓨터 화면 우선(휴대폰은 깨지지 않을 정도)

## 지금 단계

1단계 — **핵심 화면 완성(가상 데이터)**. 실제 음성 분석, Firestore 저장, PDF·WORD 출력,
배포는 다음 단계에서 붙입니다.

| 화면 | 상태 |
| --- | --- |
| 열쇠 입력(접속 게이트) | 동작 |
| 첫 화면 · 지난 회의록 | 동작 (가상 데이터 3건) |
| 자료 등록(파일·링크·메모·참석자·일시) | 동작 (분석은 흉내) |
| 분석 결과(요약·결정사항·할 일·원문) | 동작 |
| 확정 · 출력 | 미리보기 + HTML 내려받기 동작, PDF·WORD는 2단계 |
| 관리자(AI 열쇠 · 엔진 선택) | 동작 (저장은 2단계에서 서버로) |

## 화면 접속 값 (1단계 시험용)

- 접속 열쇠: `meeting2026`
- 관리자 열쇠: `admin2026`

> 위 두 값은 1단계 화면 확인용 임시 값입니다. 실제 배포에서는 코드가 아니라
> 서버 환경변수로 옮기고 앱에는 저장하지 않습니다.

## AI 엔진

관리자만 열쇠를 넣고, 쓰는 사람은 등록된 AI를 그대로 씁니다.

| 서비스 | 음성 받아쓰기 | 요약·정리 | 무료 한도 |
| --- | --- | --- | --- |
| Gemini (Google) | 가능 | 가능 | 있음(카드 없이 발급) |
| ChatGPT (OpenAI) | 가능 | 가능 | 없음(유료) |
| Claude (Anthropic) | 불가 | 가능 | 없음(유료) |
| DeepSeek | 불가 | 가능 | 없음(유료, 저렴) |

무료 범위 안에서 음성 회의록까지 만들려면 Gemini를 쓰는 구성이 유일합니다.
요금·무료 한도는 2026년 10월 각사 공식 문서 기준이며 바뀔 수 있습니다.

## 실행 방법

```bash
npm install
npm run dev      # http://localhost:5181
npm run build    # dist/ 에 배포용 파일 생성
```

## 폴더 구조

```
src/
  App.tsx              화면 전환과 상태
  screens/             Lock · Home · Upload · Result · Export · Archive · Admin
  components/          TopBar · MeetingRow
  lib/                 형식 · 내보내기 · AI 제공자 정의 · 설정
  mock/data.ts         가상 회의록 데이터와 분석 흉내
  styles.css           전체 디자인(검정·회색)
```

## 안전 원칙

- AI 열쇠는 화면 코드에 넣지 않고 서버에서만 사용합니다.
- 저장한 열쇠는 다시 보여 주지 않고 끝 4자리만 표시합니다.
- 데이터베이스는 기본 차단, 허용된 사람만 접근하도록 규칙을 겁니다.
- 확정 전 회의록은 저장하지 않고, 확정은 사람이 직접 누릅니다.
