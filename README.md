# Meeting-Minutes-Report · 회의록 보고서

회의 녹음/녹화 또는 메모를 분석하고, 사람이 수정·확정한 회의록만 Firebase Firestore에 저장하는 웹앱입니다. 받아쓰기는 Gemini/OpenAI, 요약은 DeepSeek/Claude/OpenAI/Gemini 중 각각 선택합니다.

## 구성
- React + TypeScript + Vite, Vercel Node.js 24 서버 함수
- Firebase Admin SDK / Firestore (클라이언트 직접 접근 전면 차단)
- 공유 접속 열쇠 + 별도 관리자 열쇠, 8시간 HttpOnly 보안 세션
- 네 제공사의 API 키를 관리자 화면에서 각각 등록하며 서버에서 AES-256-GCM으로 암호화해 저장합니다. 일반키·관리자키 및 구독 로그인과 별개입니다.
- 각 엔진의 실제 모델 목록을 조회하여 고르거나 같은 제공사의 권장 모델 자동 선택을 사용할 수 있습니다. 실패 시 다른 제공사로 자동 전환하지 않습니다.
- HTML, Word(.docx), 브라우저 인쇄 대화상자의 PDF 저장 지원

## 준비
Node.js 24에서 `npm ci` 후 `npm run build`.
Vercel 프로젝트에 아래 **비밀 환경변수**를 설정합니다. `.env` 및 인증키 JSON은 Git에 올리지 마세요.

| 변수 | 용도 |
| --- | --- |
| ACCESS_KEY | 12자 이상 일반 접속 열쇠 |
| ADMIN_KEY | ACCESS_KEY와 다른 12자 이상 관리자 열쇠 |
| SESSION_SECRET | 무작위 32자 이상 세션·암호화 키 |
| FIREBASE_SERVICE_ACCOUNT_JSON | 이 프로젝트 Firebase 서비스 계정 JSON 전체 |

`SESSION_SECRET`을 바꾸면 기존 세션과 저장된 AI 키를 읽지 못하므로 AI 키를 다시 등록해야 합니다. 권한 있는 관리자가 환경변수를 관리하세요. Firebase 서버 인증키는 Vercel에만 보관하고 필요 시 Google Cloud IAM에서 폐기·재발급하세요.

## Firebase
- 별도 프로젝트 `meeting-minutes-report`, Firestore `(default)`
- `firestore.rules`와 같이 `allow read, write: if false`인 프로덕션 규칙
- 서버 Admin SDK만 데이터베이스를 읽고 씁니다.
- 원본 음성·영상은 Firestore에 보관하지 않습니다. 업로드는 Gemini 임시 파일로 전달되며 분석 후 삭제를 시도합니다. 실패·중단 시 제공자 보존 정책이 적용될 수 있습니다.

## 사용
1. 일반 접속 열쇠로 로그인합니다.
2. 관리자는 관리자 열쇠로 추가 인증한 뒤 필요한 제공사 키를 각각 등록합니다. 연결·모델 확인은 목록 조회만 수행하며 생성은 하지 않습니다. 받아쓰기 엔진/모델과 요약 엔진/모델을 정하고 설정을 저장합니다.
3. 메모 또는 음성·영상 파일을 등록하고 선택한 제공사로의 전송·과금에 동의합니다. 링크는 참고 주소만 기록합니다. 메모만 입력하면 요약 제공사의 키만 필요합니다.
   - Gemini: 최대 100MiB 원본을 Google이 안내한 조각 크기(현재 8MiB)에 맞춰 직접 업로드합니다. API 키는 서버에만 있고 브라우저에는 이 파일에만 유효한 임시 전송 권한 URL만 전달됩니다. 완료 후 서버가 파일 ID·크기·형식·nonce를 확인합니다. Vercel 요청 크기 제한 때문에 8MiB 원본을 서버 함수로 중계하지 않습니다.
   - OpenAI: 브라우저에서 음성을 16kHz 모노 PCM WAV 60초 조각으로 변환한 후 서버를 거쳐 전사합니다. 원본은 최대 100MiB·60분이지만 예상/실제 메모리 256MiB 보호 한도가 먼저 적용될 수 있습니다. 긴 파일이나 지원되지 않는 영상은 직접 나누거나 Gemini를 선택해야 합니다. 자동으로 다른 제공사에 보내지 않습니다.
   - Claude·DeepSeek: 음성 직접 전사 엔진으로 사용하지 않으며 선택한 Gemini/OpenAI 전사 결과를 요약합니다.
4. AI 결과와 전사문을 검토·수정한 뒤 확정합니다. 초안은 브라우저 메모리에만 있으며 새로고침하면 사라집니다.
5. 확정·서버 저장이 성공한 회의록을 목록에서 다시 열고 출력합니다. 목록은 최근 200건입니다.

## 제한과 보안
- 선택한 제공사의 API 키가 있어야 분석할 수 있습니다. 데모 결과로 대체하지 않습니다. 현재 실제 처리 제공사·모델을 회의록에 함께 저장·표시합니다.
- API 키 저장과 모델 목록 조회 성공은 실제 생성의 성공·무료 사용을 보장하지 않습니다. 모델·요금·데이터 이용 조건은 각 제공자와 프로젝트 설정에서 확인하세요.
- Google 전송은 2MiB가 아닌 공급자가 안내한 분할 크기를 사용합니다. 관리자 합성 업로드 점검은 9MiB 합성 WAV만 올렸다 삭제하며 추론하지 않습니다. 실제 브라우저 CORS/분석 검증은 별도입니다.
- 오류에는 안전한 제공사·단계·코드·상태만 반환하며 공급자 원문 응답, 키, 임시 업로드 URL, 실제 회의 자료를 로그에 기록하지 않습니다.
- 음성 처리·전사·화자 구분은 정확하지 않을 수 있으며 담당자·기한은 사람이 확인해야 합니다.
- 개인정보·기밀 회의 전에는 참석자 동의와 외부 처리 서비스 조건을 확인하세요.
- 무료 요금제의 할당량을 초과하면 기능이 제한될 수 있습니다. 자동 유료 업그레이드는 하지 않습니다.
- 로그인 시도와 AI 요청은 Firestore 기반 제한을 적용합니다. 공유 열쇠를 아는 사용자는 같은 팀의 모든 회의록을 읽고 쓸 수 있습니다. 개인별 권한/감사/규정 준수가 필요한 조직에는 별도 사용자 인증·권한 설계가 필요합니다.
- 로그인은 실제 HTTPS 배포에서 검증하세요. Secure 쿠키이므로 일반 로컬 HTTP에서는 인증이 유지되지 않습니다.
- PDF는 서버 직접 생성이 아니라 브라우저 인쇄에서 'PDF로 저장'을 선택하는 방식입니다.
